# Как бесплатно выложить Tempo в интернет

Вариант для личного некоммерческого использования: **Vercel Hobby + Turso Free**. У обоих тарифов есть лимиты. Условия проверены 20 сентября 2026 года: [Vercel Hobby](https://vercel.com/docs/plans/hobby), [Turso Free](https://turso.tech/pricing).

## 1. Создать базу Turso

1. Зарегистрируйтесь на [turso.tech](https://turso.tech/) и выберите тариф Free.
2. Создайте базу **libSQL**, например `chess-tempo`, в регионе поближе к вам.
3. Скопируйте URL базы (`libsql://…turso.io`) и создайте токен базы с правом записи.

Понадобятся два значения:

| Переменная | Значение |
| --- | --- |
| `TURSO_DATABASE_URL` | URL базы из Turso |
| `TURSO_AUTH_TOKEN` | Токен этой базы |

Токен нужно вводить в настройках Vercel. Не добавляйте его в GitHub и не используйте префикс `NEXT_PUBLIC_`.

## 2. Импортировать репозиторий в Vercel

1. Откройте [vercel.com/new](https://vercel.com/new) и войдите через GitHub. Выберите Hobby / личный аккаунт.
2. Разрешите Vercel доступ к репозиторию `chess-tempo` и нажмите **Import**. Приватный репозиторий тоже подходит.
3. Framework Preset: **Next.js**. Root Directory: корень репозитория. Node.js: **24.x**.
4. В **Environment Variables** добавьте обе переменные из таблицы для **Production**. Для Preview используйте отдельную тестовую базу, если понадобятся предварительные версии.
5. Нажмите **Deploy**.

Команда сборки уже указана в `vercel.json`: `npm run deploy:build`. Она создаёт таблицы и затем собирает приложение. Миграции запоминаются в базе; последующие размещения сохраняют данные.

После успешной сборки Vercel выдаст адрес вида `https://chess-tempo-….vercel.app` с HTTPS. Скопируйте фактический адрес из панели проекта и откройте его на телефоне.

## 3. Проверить приложение

1. Зарегистрируйте аккаунт по email и паролю.
2. Добавьте двух игроков, выберите режим и запустите часы.
3. Завершите партию и сохраните результат.
4. Выйдите, войдите снова и проверьте историю.

Внешнее размещение использует новую базу: аккаунты и результаты из предыдущего демонстрационного сайта автоматически не переносятся.

## Обновления и ограничения

- Новые коммиты в `main` автоматически запускают размещение через подключение Vercel к GitHub.
- Vercel Hobby предназначен для личных некоммерческих проектов. Для платного сервиса или бизнеса выберите подходящий тариф.
- При исчерпании бесплатных лимитов приложение может стать недоступно до их обновления. Следите за Usage в обеих панелях.
- Адрес `vercel.app` бесплатный; свой домен покупать необязательно.
- Подтверждение email и восстановление пароля письмом в текущей версии не реализованы.

## Если сборка или вход не работают

- **Add TURSO_DATABASE_URL…** — добавьте переменные в окружение нужного размещения и нажмите Redeploy.
- **Unauthorized / token expired** — обновите токен базы в Vercel и повторите размещение.
- **Use a remote Turso database…** — на Vercel нужен URL Turso, а не `file:…` из локального примера.
- Репозиторий не виден в Vercel — проверьте доступ GitHub-приложения Vercel к этому репозиторию.

Документация: [Turso SDK](https://docs.turso.tech/sdk/ts/reference), [размещения Vercel](https://vercel.com/docs/deployments).
